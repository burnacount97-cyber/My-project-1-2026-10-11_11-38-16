JUNGLE TERRAIN - UNITY
=======================

Esto contiene SOLO el terreno 3D de una selva.
No incluye árboles, río, edificios, personajes ni objetos.

Archivos:
- JungleHeightmap16.png -> relieve del terreno
- JungleGround.png -> textura simple verde/tierra
- Editor/JungleTerrainImporter.cs -> generador para Unity

USO:
1. Crea un proyecto Unity 2022.3 LTS o Unity 6.
2. Copia la carpeta Assets/JungleTerrain dentro de Assets.
3. Abre Unity y espera a que importe.
4. Menú: Tools > Jungle Terrain > Crear Terreno.
5. Pulsa CREAR TERRENO 3D.

El resultado será:
Assets/JungleTerrain/JungleTerrain.unity

Tamaño inicial: 500 x 500 m
Altura máxima: 90 m
Resolución: 513 x 513
